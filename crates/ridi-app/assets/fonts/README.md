# Bundled fonts

This directory contains the KG Happy font family copied from:

`/home/toms/Downloads/kg_happy`

Included files:

- `KGHAPPY.ttf`
- `KGHAPPYSolid.ttf`
- `KGHAPPYShadows.ttf`
- `KGFonts-TOU.txt`

The map renderer prefers `KGHAPPY.ttf` and falls back to the other KG Happy variants if needed.
